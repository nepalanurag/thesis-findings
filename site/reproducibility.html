How to rerun it

The complete setup is documented in REPRODUCE.md. The short version: R (≥ 4.3) with tidyverse, glmnet, grpreg, pROC, Matrix, patchwork, and SKAT; download the TCGA files (~410 MB) from cBioPortal with the committed dl_rna.py and dl_clinical.py scripts; then run the scripts in order, real, v3, five-arm, stability, basal, simulation. All seeds are fixed, so a rerun on the same data and package versions reproduces the runs bit-for-bit. The stability scripts are resumable: already-computed run/variant results are skipped on relaunch.

Archival code. The thesis-as-written scripts (code/main.r, code/tcga_brca_multimodal_selection.R) are kept with explicit archival headers for provenance. They are not part of the rerun pipeline; use code/frozen_tcga/. One comprehensive script, tcga-brca-validation.R, is committed for provenance with its table mapping still to be confirmed rather than guessed.
