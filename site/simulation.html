Integrative Feature Selection for Multi-Modal Data via Permutation-Assisted Group Lasso

Anurag Nepal · San Francisco State University · May 2026

Key findings Background Methods Simulation study TCGA-BRCA results

1. Background

This is the simulation study the thesis was built on, run from the thesis notebook (one line fixed: a vector was being indexed with $final_selection). The idea is simple: when the truth is known, you can check whether the method finds it.

One thing to read first: this notebook runs the thesis's original adaptive weights, the SKAT-p-value version documented on the Methods page as invalid for standardized continuous expression data. The SKAT p-values collapsed to 1 for nearly every group, so the "adaptive" penalty carried no signal information, it was purely size-proportional. Everything on the TCGA-BRCA page uses the fixed shrunk-Wald-z weights. What follows is what the original version did, which turns out to be a clean demonstration of why the fix was needed.

2. Setup

One scenario: n = 100 samples, a binary outcome drawn from a logistic model on three latent variables. Each latent variable generates a block of 10 correlated features (30 true causal features total), plus 200 noise features. Five independent runs; within each run, 25 permutations of a decoy-based lambda selection, keeping features selected in at least half the permutations. Five methods compared: baseline lasso, early fusion (one joint group-lasso model) and late fusion (per-modality models, combined picks), each with standard correlation-rank penalties and with the original SKAT-based adaptive penalties.

Selection quality by method: F1 against the known 30 causal features, mean and one SD over 5 runs.

The adaptive rows did not win. With the original SKAT weights they selected 70 to 80 features with false discovery rates around 0.7: the weights carried no signal, so "adaptive" meant almost unpenalized noise groups getting in. This is exactly the failure mode the Methods page diagnoses, reproduced here on known truth before it ever touched real data.

Two cleaner results did hold. Standard group lasso on the joint model nearly perfectly recovered the truth (F1 0.96, zero false discoveries, 28 of 30 features), and early fusion beat late fusion for the standard penalty (F1 0.96 vs 0.77). Note the AUC column: baseline lasso predicts well (AUC 0.93) while selecting almost nothing real (sensitivity 0.10), and the best-selecting method has the lowest AUC. Prediction and selection are different jobs; this study scores selection.

Caveats. Five runs is small, so the standard deviations are wide and any single row could shift with more runs. The adaptive rows reflect the original flawed weights only; they say nothing about the fixed shrunk-Wald-z weights used on the real-data pages.

4. Takeaway

The simulation did its job: it showed that the thesis's original adaptive weighting failed on known truth, selecting mostly noise. That failure is what motivated the SKAT correction. The standard-penalty results also established the baseline the method had to beat: a joint early-fusion group lasso that finds 28 of 30 true features with no false discoveries. Everything reported on the TCGA-BRCA page is judged against that bar, using the fixed weights.
